# Feature Proposal: Smart Fix (AI Auto-Correction Engine)

## 1. Summary

**Smart Fix** est un moteur d’auto-correction piloté par IA qui détecte automatiquement les erreurs dans les nœuds Python, propose des correctifs intelligents, et permet de les appliquer en un clic. Il s’appuie sur les messages d’erreurs générés lors du calcul, le code de chaque nœud et le contexte du graphe.

Cette fonctionnalité transforme Econ Graph en un assistant de modélisation à la fois pédagogique et productif, unique sur le marché.

---

## 2. Goals

* Réduire drastiquement les erreurs de calcul dues à des fautes simples.
* Aider les utilisateurs novices à comprendre pourquoi leur modèle échoue.
* Accélérer le prototypage pour les Data Analysts, consultants et étudiants.
* Améliorer la qualité des modèles (absence d'exceptions silencieuses).

---

## 3. User Stories

### ● Analyste / Consultant

> "Quand une erreur apparaît dans un nœud, je veux qu’on me propose automatiquement une correction logique."

### ● Étudiant / Apprenant Python

> "J’aimerais que l’outil m’explique pourquoi mon code plante et comment corriger."

### ● Ingénieur financier

> "Je veux cibler les nœuds problématiques et appliquer un correctif fiable sans tout relire."

---

## 4. Functional Specification

### 4.1 Déclenchement

Smart Fix s’active lorsqu’un nœud génère une erreur lors du calcul :

* ZeroDivisionError
* TypeError
* ValueError
* Variable non définie
* Paramètre non utilisé
* Calcul impossible dû à une dépendance manquante

### 4.2 Actions IA disponibles

Pour chaque erreur détectée, l’IA propose :

1. **Patch direct** (ex : `if revenue == 0: return 0`).
2. **Patch robuste** (vérifications + fallback scenario).
3. **Explication pédagogique** du bug.
4. **Refactorisation** pour clarifier le code.
5. **Proposition alternative** (ex : division sécurisée, cast en float, arrondi).

### 4.3 Flux utilisateur

1. Un nœud passe en rouge (tonalité *error*).
2. Bouton apparaît : **"Fix with AI"**.
3. L’utilisateur ouvre un volet latéral contenant :

   * le code actuel,
   * le message d’erreur brut,
   * la suggestion de correction,
   * une explication.
4. L’utilisateur valide la correction → le code est mis à jour.

### 4.4 Paramètres de contrôle

* Niveau de correction (Safe / Balanced / Aggressive)
* Affichage ou non des explications pédagogiques

---

## 5. Technical Architecture

### 5.1 Backend

Nouveau endpoint :

```
POST /ai/smart-fix
```

Payload :

* node_id
* current_code
* error_trace
* project graph context

Output :

* corrected_code
* explanation
* confidence_score

### 5.2 Frontend

* Détection automatique des node.computation_error
* Bouton "Fix with AI" sur la node sheet
* Diff viewer du code avant/après

### 5.3 Sandbox

* Exécution sécurisée de la version corrigée (test-run)
* Si OK → patch proposé
* Si KO → fallback vers proposition 2

---

## 6. UX Flow

1. L’utilisateur calcule le graphe.
2. Un nœud échoue → coloration rouge.
3. Paneau latéral : erreur affichée.
4. Bouton "Fix with AI".
5. L’IA analyse l’erreur + suggère un correctif.
6. L’utilisateur voit un diff propre.
7. Validation → sauvegarde.

---

## 7. KPI / Metrics

* Pourcentage de modèles corrigés automatiquement
* Réduction du temps moyen avant résolution d’une erreur
* Nombre de Smart Fix appliqués
* Amélioration du taux de calcul complet (compute/all)

---

## 8. Roadmap

**Étape 1 — Déclenchement + Endpoint IA (1 jour)**

* Detection erreurs + payload correct

**Étape 2 — UI Fix Panel (2 jours)**

* Bouton + paneau + diff viewer

**Étape 3 — Sandbox + Test-run automatique (1 jour)**

* Sécuriser les patchs

**Étape 4 — V2 (pédagogie + refactor intelligent) (2 jours)**

* Explications détaillées
* Correction multi-nœuds

---

## 9. Risques & Limitations

* L’IA peut créer des patchs "trop permissifs".
* Corriger un nœud peut révéler d’autres erreurs en cascade.
* Sandbox doit être sûre pour éviter des injections via l’IA.

---

## 10. Impact stratégique

Smart Fix :

* réduit la friction,
* augmente l’adoption,
* transforme Econ Graph en **assistant de modélisation autonome**,
* offre un avantage pédagogique très fort.

C’est une fonctionnalité qui vaut à elle seule un chapitre dans un pitch deck.
