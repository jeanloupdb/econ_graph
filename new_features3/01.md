# Feature Proposal: Public Viewer Mode (Read-Only)

## 1. Summary

Le **Public Viewer Mode** permet de partager un modèle Econ Graph en mode lecture seule, sans exposer l’éditeur, le code Python ni les capacités de modification. Il transforme un projet en une visualisation sécurisée, épurée et compréhensible pour un public externe (clients, étudiants, collègues, comités de direction).

C’est le premier "game changer" prioritaire pour transformer Econ Graph en un outil de présentation professionnelle, de pédagogie et de collaboration légère.

---

## 2. Goals

* Permettre de **partager un modèle** via un lien public sécurisé.
* Offrir un **canvas interactif** (zoom/pan) mais sans édition.
* Afficher les **valeurs calculées** et les **scénarios** sans révéler le code source.
* Proposer une vue simplifiée pour les non-techniciens.
* Supporter l’intégration dans un LMS, une page web ou une présentation.

---

## 3. User Stories

### ● Consultant / Analyste

> "Je veux montrer mon modèle à un client sans lui donner accès au code ni au builder."

### ● Enseignant / Formateur

> "Je veux partager un modèle avec mes étudiants qui peuvent manipuler les scénarios mais pas casser le graphe."

### ● Décideur / Comité

> "Je veux visualiser les résultats, naviguer dans le graphe, mais je n’ai pas besoin d’éditer le modèle."

---

## 4. Functional Specification

### 4.1 Modes de visualisation

* **Canvas read-only** (React Flow en mode pointer uniquement)
* **Affichage des valeurs réelles + scénario sélectionné**
* **Menu Scénarios** accessible en lecture seule
* **Pas d’accès au compute_definition**
* **Pas de déplacement de nœuds**

### 4.2 Options de partage

* Lien public (token unique, non indexable)
* Mode "connexion requise"
* Option "Scénarios visibles / non visibles"

### 4.3 Privileges d’accès

| Élément               | Auteur | Viewer |
| --------------------- | ------ | ------ |
| Voir le canvas        | ✔      | ✔      |
| Voir les valeurs      | ✔      | ✔      |
| Changer de scénario   | ✔      | ✔      |
| Modifier scénario     | ✔      | ✖      |
| Modifier un nœud      | ✔      | ✖      |
| Voir le code Python   | ✔      | ✖      |
| Modifier la structure | ✔      | ✖      |
| Mode IA Architect     | ✔      | ✖      |

### 4.4 Sécurité

* Nouveau champ en DB : `project.public_view_token`
* Endpoint dédié : `GET /viewer/{public_token}`
* Token UUID v4 avec expiration optionnelle

---

## 5. Technical Architecture

### Backend

* Nouveau endpoint public : `/viewer/{token}`
* Charge :

  * Graph nodes
  * Edges
  * Scenarios (read-only)
  * Values (compute/all)
* Expose uniquement les champs nécessaires : `label`, `value`, `pos`, `unit`, `scenario_delta`.
* Filtrage strict du `computation_definition`.

### Frontend

* Nouveau layout : `ViewerPage.tsx`
* Canvas React Flow en mode view-only
* Sidebar minimaliste (scénarios + valeurs clés)
* En-tête : nom du projet, bouton copie-lien

---

## 6. UX Flow

1. L’utilisateur ouvre un projet.
2. Menu "Share" → "Generate Viewer Link".
3. Le backend crée `public_view_token`.
4. L’utilisateur partage l’URL.
5. Le viewer accède à une **vue simplifiée** :

   * Canvas
   * Liste des scénarios
   * Valeurs visibles
   * Pas de code
   * Pas de panneaux d’édition

---

## 7. KPI / Metrics

* Taux de partage de modèles
* Nombre de vues par lien public
* Temps passé sur un viewer
* Conversions viewer → inscription

---

## 8. Roadmap

**Étape 1 — Backend (1 jour)**

* Endpoint token + sécurisation
* Filtrage des champs node/edge

**Étape 2 — Frontend minimal (2 jours)**

* Page viewer
* Canvas locked
* Lecture scénarios

**Étape 3 — Améliorations (2–3 jours)**

* Mode embed (iframe)
* Options explications automatiques
* Mode présentation

---

## 9. Risques & Limitations

* Manque de collaboration temps réel (à venir)
* Besoin d’une sandbox sûre avant ouverture totale au public
* Nécessité de limiter les données sensibles dans les modèles partagés

---

## 10. Impact stratégique

Le **Public Viewer Mode** crée :

* une adoption virale (partage facile),
* une proposition de valeur claire pour consultants, profs, analystes,
* un pont vers un écosystème de modèles publics (Notion-style),
* un premier pas vers la collaboration.

C’est l’une des features les plus simples à développer et les plus riches en retours produit immédiats.
